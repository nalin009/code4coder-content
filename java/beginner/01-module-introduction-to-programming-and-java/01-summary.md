# ☕ Introduction to Java

Java is a **high-level, object-oriented programming language** widely used for building web applications, mobile applications, enterprise software, and more.

---

## ✨ Features of Java

Java provides several important features that make it a popular programming language:

* 🧩 **Object-Oriented** — Java follows object-oriented programming principles.
* 🌐 **Platform Independent** — Java programs can run on different platforms using the JVM.
* 🔐 **Secure** — Java provides several built-in security features.

---

## 💻 Example

Here is a simple Java program that prints `Hello` to the console:

```java
public class HelloWorld {

    public static void main(String[] args) {

        System.out.println("Hello");

    }

}
```

### 📝 Output

```text
Hello
```
