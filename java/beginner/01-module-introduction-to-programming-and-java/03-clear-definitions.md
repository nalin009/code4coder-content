# 3. Clear Definitions 📚

## 3.1 What Is Programming? 💻

**Programming** is the process of writing a **set of instructions**, called **code**, that a computer can execute to perform specific tasks.

In simple terms, programming is the process of **telling a computer what to do and how to do it**.

---

## 3.2 What Is a Programming Language? 🧩

A **programming language** is a formal language that provides a **set of rules and instructions** that allow humans to communicate with computers.

It acts as a bridge between **human logic** and **machine execution**, allowing developers to write instructions that can eventually be translated into a form the computer can execute.

Examples of programming languages include:

* Java ☕
* Python 🐍
* C
* C++
* JavaScript
* Go

---

## 3.3 What Is Java? ☕

**Java** is a **high-level, class-based, object-oriented, general-purpose programming language** developed by **Sun Microsystems** and first released in **1995**.

Java was designed with goals such as **simplicity, security, portability, and platform independence**.

Java applications are compiled into **bytecode**, which can run on any platform that provides a compatible **Java Virtual Machine (JVM)**.

> **Write Once, Run Anywhere (WORA)** 🌐

Sun Microsystems was acquired by **Oracle Corporation** in 2010, and Oracle now maintains and develops the Java platform.

---

## 3.4 Interview-Safe Definition 🎯

> **Java is a general-purpose, class-based, object-oriented programming language designed to be platform-independent by compiling source code into bytecode that can run on any platform with a compatible Java Virtual Machine (JVM).**

### 🔑 Key Points

* **General-purpose** — Can be used to build different types of applications.
* **Class-based** — Java programs are primarily organized around classes and objects.
* **Object-oriented** — Supports core OOP concepts such as encapsulation, inheritance, polymorphism, and abstraction.
* **Platform-independent** — Java bytecode can run on different operating systems through the JVM.
* **High-level** — Provides abstractions that make development easier than programming directly in machine code.
