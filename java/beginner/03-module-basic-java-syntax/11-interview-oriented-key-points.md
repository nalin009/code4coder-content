## 10. Interview-Oriented Key Points (Quick Revision)

---

**a.** **Java program structure:** Package → Import → Class → Members → main method

**b.** **main method signature:** public static void main(String[] args) (unchanged since Java 1.0)

**c.** **Three comment types:** Single-line (//), multi-line (/* */), Javadoc (/** */)

**d.** **Statements end with semicolon:** Missing semicolon = compilation error

**e.** **Blocks define scope:** Variables declared in a block die when block ends

**f.** **Local variables on stack:** Fast allocation/deallocation, no GC

**g.** **println adds newline, print does not:** Choose based on output needs

**h.** **Escape sequences processed at compile-time:** No runtime overhead

**i.** **Case-sensitive language:** System ≠ system

**j.** **Indentation is cosmetic:** Compiler ignores whitespace, but readability matters

**k.** **Comments have zero runtime cost:** Stripped during compilation

**l.** **Minimize scope:** Declare variables in smallest scope possible

**m.** **Self-documenting code:** Prefer clear names over excessive comments

**n.** **Use Javadoc for public APIs:** Industry standard for documentation

**o.** **Follow naming conventions:** Classes (PascalCase), variables (camelCase), constants (UPPER_SNAKE_CASE)

#### 10.1 One-Line Exam / Interview Answer
**Q:** What is Java syntax?

**A:** Java syntax is the set of rules defining how to write correctly structured Java programs that the compiler can parse and the JVM can execute.
